# BMI App
A Kotlin / Jetpack Compose project to learn the basics of Android native development such as navigation, compostables, functions, variables and syntax's.
In this app we calculate BMI using height and weight of the user inputs placed in custom app cards.

## Features
- Increase and decrease weight, height, age, inputs.
- Manage basic state using rememberSaveable.
- Creations of custom app cards.
- Navigation 3

  ## Tech Stack
  - Kotlin
  - Jetpack Compose

  - Android Studio
